===============================================================================
 TILEHUNT
===============================================================================

Arborescence attendue, a cote de tilehunt.py :

    Tiles/
      tilehunt.py
      commandes_bases.txt
      Data/      les telechargements, les npz, les bases locales
      Maps/      les html generes
      Runs/      un sous-dossier par parcours (cree tout seul)

tilehunt cree Data/, Maps/ et Runs/ tout seul au premier lancement. Mais
l'etape 2 telecharge DANS Data/ avec curl, avant qu'aucune commande tilehunt
n'ait tourne, et curl ne cree pas de dossier : il faut donc creer Data/ et
Maps/ a la main au depart.


===============================================================================
 WINDOWS
===============================================================================

--- 1. Bibliotheques ---------------------------------------------------------

    pip install numpy scipy shapely osmium rasterio

  numpy et scipy : calcul et plus courts chemins
  shapely        : les frontieres (masque France, regions, departements)
  osmium         : lecture du .osm.pbf   (le paquet s'appelle osmium, pas
                   pyosmium)
  rasterio       : les altitudes Copernicus, etape 3 seulement


--- 2. Donnees ---------------------------------------------------------------

  Creer les dossiers d'abord, curl ne le fera pas :

    mkdir Data
    mkdir Maps

  Puis telecharger :

    curl.exe -L -o Data\france-latest.osm.pbf https://download.geofabrik.de/europe/france-latest.osm.pbf
    curl.exe -L -o Data\countries.geojson https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson
    curl.exe -L -o Data\regions.geojson https://raw.githubusercontent.com/gregoiredavid/france-geojson/master/regions.geojson
    curl.exe -L -o Data\departements.geojson https://raw.githubusercontent.com/gregoiredavid/france-geojson/master/departements.geojson

  Tailles : le pbf fait plusieurs Go, les trois geojson 3,0 / 1,4 / 3,4 Mo.


--- 3. Base de donnees locale  (~25-30 min) ----------------------------------

    python tilehunt.py genBDD --pbf france-latest.osm.pbf --out france.paved.npz --db Database_OSM --dem-db DEM_DB -v

  Routes et altitudes dans la meme passe. Interrompue, relancer la meme
  ligne : ce qui est fini est saute. Seule etape qui touche au reseau,
  pour les altitudes (~560 Mo au final dans Data\DEM_DB).


--- 4. Masque France ---------------------------------------------------------

    python tilehunt.py mask --boundary countries.geojson --iso FRA --clip -5.3,41.2,9.7,51.2 --out france.mask.npz


--- 5. Tuiles deja roulees, depuis Statshunters  (facultatif) ----------------

  D'abord creer un lien de partage, une seule fois, sur :
  https://www.statshunters.com/share

  Puis :

    python tilehunt.py genVisited --share https://www.statshunters.com/share/TONCODE

  Le lien est retenu dans Data\statshunters.txt, donc par la suite un simple
  genVisited suffit pour rafraichir :

    python tilehunt.py genVisited

  Options utiles :
    --type Ride           ne garder que le velo
    --since 2025-01-01    ignorer les activites plus anciennes

  Sortie : Data\visited.npz, plus le nombre de tuiles tenues et le carre
  maximum actuel.

  ATTENTION : le lien de partage est un secret. Qui l'a peut lire tout ton
  historique. Data\statshunters.txt ne doit pas partir dans git.


--- 6. Carte interactive -----------------------------------------------------

    python tilehunt.py buildmap --tiles france.paved.npz --mask france.mask.npz --boundary countries.geojson --regions regions.geojson --departements departements.geojson --clip-to-mask --basemap esri-gray --visited visited.npz --out france.html

  Sans l'etape 5, enlever simplement  --visited visited.npz


--- 7. Les parcours ----------------------------------------------------------

  Ouvrir Maps\france.html, choisir SquarePlanner ou TileSeeker, suivre les
  etapes, copier les deux commandes donnees par le panneau.

  Reglages par defaut du solveur, inutile de les ecrire :
    --cands 6            jonctions candidates par tuile
    --seconds 80         budget pour ameliorer l'ordre de visite
    --reopt-seconds 30   budget apres l'elagage des visites redondantes
    --prune-seconds 60   budget de l'elagage lui-meme

  Dans Layers :
    visited        les tuiles que tu as, en bleu, par-dessus tout le reste
    remove green   retire les tuiles avec route
    remove red     retire les tuiles sans route

  Les trois ensemble : couper le vert et le rouge ne laisse que tes tuiles.
  Une tuile rouge deja roulee s'affiche bleue ; couper visited la rend
  rouge a nouveau.


===============================================================================
 LINUX / MACOS
===============================================================================

--- 1. Bibliotheques ---------------------------------------------------------

  Un environnement virtuel, pour ne rien installer a l'echelle du systeme :

    python3 -m venv .venv
    source .venv/bin/activate
    pip install numpy scipy shapely osmium rasterio

  A refaire a chaque nouveau terminal :  source .venv/bin/activate

  Sans venv, les distributions recentes (Debian 12+, Ubuntu 23.04+) refusent
  d'installer dans le python du systeme. Passer outre :

    pip install --break-system-packages numpy scipy shapely osmium rasterio


--- 2. Donnees ---------------------------------------------------------------

    mkdir -p Data Maps
    curl -L -o Data/france-latest.osm.pbf https://download.geofabrik.de/europe/france-latest.osm.pbf
    curl -L -o Data/countries.geojson https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson
    curl -L -o Data/regions.geojson https://raw.githubusercontent.com/gregoiredavid/france-geojson/master/regions.geojson
    curl -L -o Data/departements.geojson https://raw.githubusercontent.com/gregoiredavid/france-geojson/master/departements.geojson


--- 3. Base de donnees locale  (~25-30 min) ----------------------------------

    python3 tilehunt.py genBDD --pbf france-latest.osm.pbf --out france.paved.npz --db Database_OSM --dem-db DEM_DB -v


--- 4. Masque France ---------------------------------------------------------

    python3 tilehunt.py mask --boundary countries.geojson --iso FRA --clip=-5.3,41.2,9.7,51.2 --out france.mask.npz

  Noter le  --clip=  avec un signe egal. Les deux formes marchent, mais
  certains shells coupent une valeur commencant par un tiret.


--- 5. Tuiles deja roulees, depuis Statshunters  (facultatif) ----------------

  Lien de partage a creer sur https://www.statshunters.com/share , puis :

    python3 tilehunt.py genVisited --share https://www.statshunters.com/share/TONCODE

  Ensuite, pour rafraichir :

    python3 tilehunt.py genVisited

  Garder Data/statshunters.txt hors de git : c'est un secret.


--- 6. Carte interactive -----------------------------------------------------

    python3 tilehunt.py buildmap --tiles france.paved.npz --mask france.mask.npz --boundary countries.geojson --regions regions.geojson --departements departements.geojson --clip-to-mask --basemap esri-gray --visited visited.npz --out france.html


--- 7. Les parcours ----------------------------------------------------------

    xdg-open Maps/france.html        (Linux)
    open Maps/france.html            (macOS)
